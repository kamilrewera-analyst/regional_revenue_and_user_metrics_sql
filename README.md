# Regional Revenue & User Acquisition Analytics

This repository demonstrates advanced SQL data manipulation using Common Table Expressions (CTEs), conditional aggregations, and window functions to aggregate financial performance and user session activity on a continental level.

## Overview & Objectives

The goal of this query is to analyze revenue distribution, platform performance across device types (Mobile vs. Desktop), and user acquisition/engagement metrics per continent. 

Key analytical focus areas:
*   **Regional Revenue Analysis:** Calculating total revenue per continent along with its percentage contribution to total global revenue (`% Revenue from Total`).
*   **Device Breakdown:** Categorizing revenue streams into Mobile (`Revenue from Mobile`) and Desktop (`Revenue from Desktop`).
*   **User Engagement & Verification:** Tracking total session activity (`Session Count`), registered accounts (`Account Count`), and verified user accounts (`Verified Account`).

---

## SQL Pipeline Architecture

The query is built using a structured CTE approach:

1.  `device_revenue`: Joins orders, products, sessions, and session parameters to calculate total regional revenue and perform conditional aggregation (`CASE WHEN`) for mobile vs. desktop sales.
2.  `acc_and_session`: Aggregates distinct account IDs, verified accounts, and unique web sessions mapped to each continent using multiple `LEFT JOIN` operations.
3.  **Final Query:** Joins the revenue and user statistics CTEs, applies window functions (`SUM() OVER()`) to compute overall percentages, rounds values for reporting, and sorts the results by total revenue in descending order.

---

## Tech Stack & Key Concepts

*   **Query Language:** SQL (Compatible with Google BigQuery)
*   **Advanced SQL Concepts:**
    *   Common Table Expressions (CTEs)
    *   Conditional Aggregation (`SUM(CASE WHEN ... END)`)
    *   Window Functions (`OVER()`)
    *   Multi-table Joins (`JOIN`, `LEFT JOIN`)
    *   Data Formatting & Rounding (`ROUND()`)
